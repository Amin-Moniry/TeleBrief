# TeleBrief Bot 🤖

ربات هوشمند دریافت و خلاصه‌سازی اخبار تلگرام با استفاده از هوش مصنوعی

## ✨ ویژگی‌های جدید

### 📱 دو دسته خبری
- **🤖 هوش مصنوعی**: اخبار AI، ML، مدل‌های جدید، ابزارها
- **🔒 امنیت سایبری**: CVE، حملات، بدافزار، ابزارهای امنیتی

### 🎯 انتخاب هوشمند
- بررسی خودکار کانال‌ها (حداکثر 300 پیام از هر کانال)
- انتخاب هوشمند مهم‌ترین اخبار با AI
- فیلتر کردن تبلیغات و کلیک‌بیت

### 📊 گزارش‌دهی شفاف
- نمایش تعداد پیام‌های بررسی شده
- حتی اگر خبر خاصی نبود، خلاصه کلی از محتوای روز
- لینک مستقیم به پیام اصلی در کانال

### 💬 تعامل ساده
- دکمه‌های انتخاب دسته
- پیام خوش‌آمدگویی فقط برای کاربران جدید
- پیام "در حال پردازش..." تا کاربر بفهمه چه اتفاقی می‌افتد

## 📋 دستورات

- `/start` - شروع به کار و خوش‌آمدگویی
- `/todaynews` - دریافت اخبار 12 ساعت گذشته (با انتخاب دسته)
- `/help` - راهنمای استفاده

## 🔧 نحوه کار

1. کاربر `/todaynews` را می‌فرستد
2. ربات دو دکمه نمایش می‌دهد: AI / Security
3. کاربر یکی را انتخاب می‌کند
4. ربات:
   - کانال‌های مربوط به دسته انتخابی را اسکن می‌کند
   - پیام‌های 12 ساعت گذشته را جمع‌آوری می‌کند
   - با AI مهم‌ترین اخبار را انتخاب می‌کند
   - تعداد پیام‌های بررسی شده را نمایش می‌دهد
   - اگر خبری یافت شد: عنوان + خلاصه + دلیل اهمیت + لینک
   - اگر خبری نیافت: خلاصه کلی از محتوای روز

## ⚙️ متغیرهای محیطی

این موارد باید در GitHub Secrets تنظیم شوند:

- `API_ID` - Telegram API ID
- `API_HASH` - Telegram API Hash
- `SESSION_STRING` - Telethon Session String
- `BOT_TOKEN` - Telegram Bot Token
- `MY_CHAT_ID` - Chat ID برای دریافت پیام‌ها
- `XKIRO_API_KEY` - کلید API هوش مصنوعی
- `API_BASE_URL` - آدرس API هوش مصنوعی
- `DEFAULT_MODEL` - مدل پیش‌فرض (مثلاً deepseek/deepseek-v4-pro)

## 📦 وابستگی‌ها

- `telethon` - کلاینت تلگرام
- `requests` - درخواست‌های HTTP

## 🔄 GitHub Actions

- **check-command.yml**: هر 5 دقیقه دستورات جدید را چک می‌کند
- **daily.yml**: هر 12 ساعت گزارش خودکار ارسال می‌کند

## 📝 فایل‌های مهم

- `command_bot.py` - هندلر دستورات و دکمه‌ها
- `digest_core.py` - منطق اصلی جمع‌آوری و تحلیل
- `bot_state.json` - ذخیره وضعیت کاربران و پیام‌های پردازش شده
- `main.py` - اسکریپت ساده برای اجرای digest
